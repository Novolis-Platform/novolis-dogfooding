# StudioChromeLab

Dogfoods **Novolis.Avalonia.Controls** (ChoiceDialog, FilteredPickerDialog, MarkedListBox, JobQueuePanel) and **Novolis.Avalonia.Studio** (FocusMode, StatusBrushes), with optional **Novolis.IO.Processes** job enqueue.

```powershell
dotnet run --project novolis-dogfooding/apps/avalonia/StudioChromeLab
```
