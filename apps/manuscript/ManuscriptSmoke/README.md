# ManuscriptSmoke

Dogfoods **Novolis.Markup.Manuscript** and **Novolis.Audio.Voice.Manuscript** from GitHub Packages (`2026.1.*`).

Parses chapter callout metadata / word count, then builds a TTS **SpeechPlanner** dry-run (no synthesis).

```powershell
dotnet restore
dotnet run --project apps/manuscript/ManuscriptSmoke
```
